# Learning

- An agent record and an actual provider request are different evidence. The
  pilot measured real agent_execute outputs, timing and returned token counters.
- A plausible parser can silently turn omitted fields into zero counts. Strict
  validation and tests for all-zero incomplete records catch that mistake.
- Detector matches are observations, not necessarily vulnerabilities. Manual
  review distinguished direct trigger emission from quoted/refusal false positives.
- A system instruction is a mitigation to measure, not an access-control boundary.
  It did not improve this four-prompt sample.
- Garak attempt snapshots can repeat and this curated driver leaves them status 1.
  Counting snapshots would inflate the denominator; use validated evaluator rows.
- Audit counts include dependency relationships and optional lockfile nodes. Check
  installation scope and reachability rather than treating every entry as a
  separate proven exploitable flaw.
- Windows app approval is separate from OS administrator rights and network
  sandbox permissions. A timed-out automatic review is not a safety verdict.
